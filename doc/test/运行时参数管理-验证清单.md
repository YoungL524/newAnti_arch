# 运行时参数管理 — 验证清单

## 顺序契约（不可回退）

1. `validate()` 失败时不 publish、不 set
   - 输入超出 0..255 的值 → API 返回 400，`RuntimeSettingsService::get()` 返回旧值
2. `publish()` 失败时不 set
   - 模拟 SystemBus shutdown 场景 → API 返回错误，service 快照不更新
3. publish 成功后 set，并最终触发 `DphPublisher.applyRuntimeSettings()`
   - PUT 成功后读取 `/api/runtime-settings` 确认 settings 更新
   - 确认 `DphPublisher` 中 `F_UI_Freq_Ctrl` / `F_UI_Wave_Ctrl` 新值生效
   - 确认 `sceneNumber` / `sendCount` 不被重置

## 校验规则

| 输入 | 预期 |
|------|------|
| 缺 `frequencyControl` | 400: 不能为空 |
| `frequencyControl: "abc"` | 400: 必须是数字 |
| `frequencyControl: 1.5` | 400: 必须是整数 |
| `frequencyControl: -1` | 400: 必须是非负整数 |
| `frequencyControl: 300` | 400: 超出范围（由 RuntimeSettingsService::validate 返回） |
| 合法值 | 200: ok，settings 返回后端确认值 |
