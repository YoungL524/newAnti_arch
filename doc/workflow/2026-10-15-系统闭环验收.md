## 静态核对结果

| 闭环 | 当前代码依据 | 静态结论及运行边界 |
| --- | --- | --- |
| 航迹接收 → 共享数据域 → 显示/归档 | `TrackIngressProducer`、`TrackWebSocketService`、`ArchiveReader` | Producer 发布，Reader 独立 cursor/固定 ScratchBuffer，Doorbell 经 Lane 合并；负载下连续性与内存仍待实测 |
| UI/API → 唯一控制 owner → UDP | `ApplicationController`、`DeviceController::sendControl/sendWorkMode/refreshControlTimer` | 双心跳在线且任务准备后 50 ms 周期；采集按钮另发一次工作/待机，无 ACK 或重试队列；发送节奏待实测 |
| 生命周期/归档故障 → SystemState → Web | `SystemStateOwner`、`StorageRuntime::reportArchiveStatus/reportArchiveGap`、`StateWebSocketService` | 唯一状态 owner、独立 revision；缺口保持降级，不由空批次清除失败；实际故障恢复待验收 |
| 任务/采集事务 → 状态/失败回滚 | `ApplicationController::activateTask/startAcquisition/stopAcquisition/updateTaskControlSettings` | 存储阶段异步，回到主线程更新 owner，失败沿既有路径回滚；数据库锁等待和断连场景待验收 |
| 归档提交 → 历史查询/回放 | `SqliteArchiveRepository::appendTrackBatch/appendEventBatch`、`ArchiveReader`、`historyApi`、`useTrackReplay` | 整批提交后推进 cursor；查询只读已提交数据，当前页有界，取消后拒绝旧响应；落库完整性待验收 |
| 程序启动/关停 → 运行记录 → 查询 | `SqliteArchiveRepository`、`StorageRuntime::listArchivedRuns`、`SqliteRuntimeRepository::readRunPage` | 正常排空后标正常退出，未闭合 run 在下次启动标异常；查询不改标记，也不推断进程存活 |
| 关停收口 → 停 Producer/控制 → 排空 | `ApplicationRuntime::stop`、`DeviceRegistryHttpService::stop`、`StorageRuntime::shutdown` | BlockingQueuedConnection 仅存在于初始化/关停屏障；运行期查询不阻塞主线程等待存储；退出时序待运行确认 |

静态门禁：TypeScript 无产物类型检查、仓库中文 Doxygen 脚本、Git diff --check 通过。
该结果不包含吞吐基准、运行期堆分配统计、SQLite 故障注入、浏览器视觉或设备联试证据。

## 用户运行验收顺序

每项记录所用代码版本、Core/UI 构建时间、数据库路径、操作时刻、截图/日志及通过或失败原因。
故障和异常退出场景使用独立验收数据库；不拿已有业务数据做破坏性操作。代理本轮不执行这些操作，不新增测试程序。

| 顺序 | 操作 | 通过标准 | 状态 |
| --- | --- | --- | --- |
| 1 启动与重连 | 编译 Core/UI，启动 Core，浏览器保持打开后正常重启 Core | HTTP/WS 恢复；System/Task/Device 快照更新，无需刷新；无活动任务显示 None，不自动恢复旧采集 | 待用户运行 |
| 2 控制与实时 | 激活任务；只发 DP，再发 DP+SP；启动 CSV；开始/停止采集，分别暂停一路心跳 | 双路在线才周期 0x0001；采集开始/停止各提交一包 0xFFFF；心跳改变不替用户启停采集；航迹正常发布、消亡 | 待用户运行 |
| 3 接收并行查询 | CSV 持续发送，同时查询全局日志、运行记录、历史任务日志与航迹 | 接收统计持续增长；查询等待不冻结心跳/控制；页面有界，无持续增长的旧页缓存；超过 200/1000 条可续页 | 待用户运行 |
| 4 任务闭环 | 创建/激活 → 开始 → 停止 → 完成 → 归档 → 历史日志/回放 | 阶段与按钮同步，历史只读已提交数据；身份按任务/采集/设备/阵面隔离；历史操作不发送设备命令 | 待用户运行 |
| 5 筛选与旧请求 | 组合域/五级 severity/设备/任务/时间，快速换条件、关闭窗口、断线重连；运行记录按状态/启动时间筛选 | 精确筛选；同毫秒分页不重复；非法条件失败；旧条件游标拒绝；旧响应不覆盖新页，SQL 错误不伪装空结果 | 待用户运行 |
| 6 正常退出 | 停止采集，正常关闭 Core，再启动后打开运行记录 | 旧 run 正常退出时间存在，异常检测时间为空；当前 run 未标记退出；版本与进程号来自真实记录 | 待用户运行 |
| 7 异常退出 | 在独立验收库下制造非正常终止，再启动并查询 | 旧 run 标检测到异常，只有异常检测时间，不补造退出时刻；当前 run 独立生成；遗留采集会话按已有恢复规则收口 | 待用户运行 |
| 8 存储失败与回滚 | 在独立验收库复现锁等待/提交失败、参数更新失败和采集绑定失败，再解除故障 | 接收/控制继续；失败请求明确返回；失败参数不替换旧快照；采集失败不遗留正常运行状态；归档失败不推进 cursor，缺口不假装恢复 | 待用户运行 |
| 9 关停在途 | 查询或写请求已受理时关闭浏览器或正常关闭 Core | 客户端断开不跳过已接受写操作的提交/回滚；关停排空后释放连接、线程和 Socket，无死锁或退出后残留进程 | 待用户运行 |

## 完成判定

上述项目用户实际运行并确认后，才能标记当前雷达系统闭环验收完成。发现失败先修对应 owner/事务/状态边界，
不引入第二条接收、存储或控制链。航迹节奏与细节优化依据现场数据单独推进；当前静态结论不等于整个产品功能已完备。
