# 雷达配置界面 · 右侧优化版

## 接入

1. 将 `RadarEditForm.tsx`、`RadarControlSettingsDialog.tsx` 替换到原组件目录。
2. 将 `RadarSettings.css` 放在上述两个组件同一目录；组件已包含 CSS import。
3. `DeviceEditDialog.tsx` 为原文件，无需修改，包内保留供核对。

继续使用项目已有的 React、Tailwind、Material Symbols 和主题变量，不增加生产依赖。CSS 使用 `rs-` 前缀，作用于右侧内容与底部操作区。

## 本次调整

- 左侧导航 JSX 原样保留。
- 右侧使用浅灰绿底色与白色分组面板；统一 38px 控件、字段间距和标题层级。
- 设备名称移到基本信息，设备标识独立展示为只读信息。
- 通信配置扩大端口宽度，对齐地址字段，移除 SQLite / revision 等实现说明。
- 阵面安装表统一列宽，单面阵 / 四面阵选择显示当前选中态。
- 通用参数按工作模式、检测与抑制、辅助功能分组；开关使用独立设置行。
- 十六进制输入的 0x 前缀合并到控件内部，校验与补码转换沿用原代码。
- 帧参数分为景幅连续、单帧测试、自定义波形；自定义波形在适用时展开，不适用时默认折叠，也可手动展开查看。折叠不卸载字段。
- 阵面参数分为射频、供电、只读部署信息；复位按钮仍不可用。
- 补充焦点、禁用和只读样式，以及右侧窄宽度的单列布局。

## 业务边界

保留原有 41 个运行参数字段的选项、值域、依赖条件、回调和提交入口。保存设备与应用任务参数仍为独立操作。本次没有修改协议、接口或安装姿态计算。

## 预览与验证

`radar-ui-preview.html` 是实际 TSX 组件构建的独立预览，使用示例数据及缺失项目模块的模拟实现。无后端请求；保存和应用只在预览内反馈，不会控制真实设备。预览的图标与主题使用本地替代资源，实际项目继续使用原资源。

已通过 TSX 转译、字段配置一致性检查和六页浏览器渲染检查（无横向溢出、无运行时异常）。模拟环境下验证了跨页草稿保留、STC 联动、非法十六进制阻止提交、自定义波形依赖、阵面复制及提交参数。项目完整类型、后端和其余源码未提供，因此预览不等同于完整项目集成验证。
