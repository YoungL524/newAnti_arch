# 运行时参数管理

## 概述

`DPH`（Data Package Header）是每 50ms 发送给雷达 CPU 的外部协议结构体，不是 UI model。`RuntimeSettingsService` 是内部运行时参数模型，UI 只与此模型交互，不直接接触协议结构体。

**关键边界**：
- `RadarWorkModeController` 独立管理工作/待机状态，RuntimeSettings 不包含 `workMode`
- `DphPublisher` 不直接订阅 SystemBus，由 bridge 订阅事件后 `QueuedConnection` 调用 `applyRuntimeSettings()`
- 第一阶段选择少量真实 DPH 字段作为可写参数（`frequencyControl`, `waveControl`），`sceneNumber` 只读

## 设计原则

- 前端不改参数就不发事件；后端继续使用上一次有效参数
- `DphPublisher` 每 50ms 只使用最新缓存发送，不主动向 UI 或 API 拉取
- UI 修改参数 → API → `RuntimeSettingsService` → 事件 → bridge → `DphPublisher.applyRuntimeSettings()`
- 工作/待机状态由 `RadarWorkModeController` 独立负责
- `F_UI_Work_Mode` 由 `RadarWorkModeController` 当前状态映射，或保持协议默认值
- `GenericPackets.h` 不包含业务类型特化（放在 `RuntimeSettingsTypes.h` 中）

## 数据流

```
UI 参数编辑
  → WebApiController
  → RuntimeSettingsService (更新内存快照)
  → SystemBus publish DphParamsChanged (source=SOURCE_RUNTIME_SETTINGS)
  → AppController/RuntimeSettingsBusBridge 按 sourceType 订阅
  → Qt::QueuedConnection invoke DphPublisher::applyRuntimeSettings(settings)
  → DphPublisher 更新本地缓存
  → QTimer 每 50ms 使用缓存组 DPH 并发送到 UDP 端点
```

## 架构边界

```
RuntimeSettingsService  ─ 不依赖 DphPublisher
DphPublisher            ─ 不依赖 SystemBus，只暴露 applyRuntimeSettings()
bridge                  ─ AppController 负责连线，SystemBus → queued invoke → DphPublisher
GenericPackets.h        ─ 不包含业务类型特化
```

## 数据模型

### 文件位置

```text
core/business/RuntimeSettingsTypes.h
```

包含 DTO 定义 + `getPayloadTypeConstant` 特化（include `GenericPackets.h`，反向不成立）。

### Settings（用户可配置参数）

```cpp
struct RadarRuntimeSettings {
    uint32_t frequencyControl = 0;  // 频率控制
    uint32_t waveControl = 0;       // 波形控制
};

// DataPackageHeader 字段映射：
// frequencyControl -> F_UI_Freq_Ctrl
// waveControl      -> F_UI_Wave_Ctrl
```

### 参数校验规则

| 字段 | 类型 | 范围 | 默认值 |
|------|------|------|--------|
| `frequencyControl` | uint32 | 0..255 | 0 |
| `waveControl` | uint32 | 0..255 | 0 |

第一阶段保守限制在 0..255，具体枚举含义待硬件协议确认后补充。越界返回：

```json
{
  "ok": false,
  "error": "frequencyControl 超出范围 0..255"
}
```

### DphPublisher::applyRuntimeSettings 语义

`DphPublisher::applyRuntimeSettings(settings)` **只更新 settings 映射字段**：

- `m_header.F_UI_Freq_Ctrl = settings.frequencyControl`
- `m_header.F_UI_Wave_Ctrl = settings.waveControl`

**不得重置**：
- `F_UI_Scene_Num`（自增连续状态）
- `F_UI_Time_Code`（每次发送更新）
- `F_UI_Work_Mode`（由 RadarWorkModeController 或协议默认值决定）
- sendCount、timer、route、DPH 发送周期

### Status（系统运行时只读状态）

```cpp
struct DphStatus {
    uint32_t currentSceneNumber = 0;  // DphPublisher 自增的当前景幅号
    uint64_t sendCount = 0;           // 已发送 DPH 包数
};
```

### DphParamsChanged 事件

```cpp
// GenericPackets.h 新增常量（不包含特化）
const uint32_t PAYLOAD_TYPE_DPH_PARAMS_CHANGED = 103;
const uint16_t SOURCE_RUNTIME_SETTINGS = 205;

// RuntimeSettingsTypes.h 中特化
template<>
inline uint32_t getPayloadTypeConstant<RadarRuntimeSettings>() {
    return PAYLOAD_TYPE_DPH_PARAMS_CHANGED;
}
```

- `sourceType = SOURCE_RUNTIME_SETTINGS`
- bridge 通过 `subscribeBySource(SOURCE_RUNTIME_SETTINGS)` 订阅，不依赖 `dispatchTarget`
- payload 为 trivially copyable `RadarRuntimeSettings`

## API

### GET /api/runtime-settings

```json
{
  "ok": true,
  "settings": {
    "frequencyControl": 0,
    "waveControl": 0
  },
  "status": {
    "currentSceneNumber": 12,
    "sendCount": 1200
  }
}
```

### PUT /api/runtime-settings

- 全量替换，不允许局部字段更新
- 后端校验完整 DTO，非法字段/越界值返回 400
- 成功时触发 `DphParamsChanged` 事件，并返回后端确认后的完整 DTO

请求：

```json
{
  "frequencyControl": 1,
  "waveControl": 2
}
```

响应：

```json
{
  "ok": true,
  "settings": {
    "frequencyControl": 1,
    "waveControl": 2
  },
  "status": {
    "currentSceneNumber": 13,
    "sendCount": 1201
  }
}
```

## 与现有模块的关系

- `DphPublisher` 不再从固定默认值构造 `DataPackageHeader`，改为从缓存读取
- `DphPublisher` 新增 `applyRuntimeSettings(const RadarRuntimeSettings&)` 方法
- `DphPublisher` 不直接访问 SystemBus
- `DphParamsChanged` 事件通过 SystemBus 发布
- 不影响 `RadarWorkModeController`（工作模式状态机仍独立运行）
- 不影响 `RadarDataProcessor`（航迹处理不依赖运行时参数）
