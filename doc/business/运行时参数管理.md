# 运行时参数管理

## 概述

`DPH`（Data Package Header）是每 50ms 发送给雷达 CPU 的外部协议结构体，不是 UI model。`RuntimeSettingsService` 是内部运行时参数模型，UI 只与此模型交互，不直接接触协议结构体。

**关键边界**：
- `RadarWorkModeController` 独立管理工作/待机状态，RuntimeSettings 不包含 `workMode`
- `DphPublisher` 不直接订阅 SystemBus，由 AppController/bridge 订阅事件后调用 `applyRuntimeSettings()`
- RuntimeSettings 第一阶段不落库，只存在内存中

## 设计原则

- 前端不改参数就不发事件；后端继续使用上一次有效参数
- `DphPublisher` 每 50ms 只使用最新缓存发送，不主动向 UI 或 API 拉取
- UI 修改参数 → API → `RuntimeSettingsService` → 事件 → bridge → `DphPublisher.applyRuntimeSettings()`
- 工作/待机状态由 `RadarWorkModeController` 独立负责，RuntimeSettings 不拥有工作模式状态
- `F_UI_Work_Mode` 由 `RadarWorkModeController` 当前状态映射，或保持协议默认值

## 数据流

```
UI 参数编辑
  → WebApiController
  → RuntimeSettingsService (更新内存快照)
  → SystemBus publish DphParamsChanged event
  → AppController / RuntimeSettingsBusBridge 订阅事件
  → Qt::QueuedConnection invoke DphPublisher::applyRuntimeSettings(settings)
  → DphPublisher 更新本地缓存
  → QTimer 每 50ms 使用缓存组 DPH 并发送到 UDP 端点
```

## 架构边界

```
UI  → 读写参数 → RuntimeSettingsService
                       ↓ SystemBus event
                  bridge (AppController 连线)
                       ↓ invokeMethod
                  DphPublisher::applyRuntimeSettings()
                       ↓
                  QTimer 使用缓存组 DPH → UDP
```

- `RuntimeSettingsService` 不依赖 `DphPublisher`
- `DphPublisher` 不直接访问 `SystemBus`，只暴露 `applyRuntimeSettings()` 方法
- SystemBus 回调线程不直接修改 QObject 状态（通过 `QueuedConnection`）

## DTO

### Settings（用户可配置参数）

```cpp
struct RadarRuntimeSettings {
    uint32_t sceneNumber = 1;       // 景幅序号（暂不作为可写字段，仅供查询）
    // 后续扩展：天线模式、频率、波形等
};
```

### Status（系统运行时只读状态）

```cpp
struct DphStatus {
    uint32_t currentSceneNumber = 0;  // DphPublisher 自增的当前景幅号
    uint64_t sendCount = 0;           // 已发送 DPH 包数
};
```

- `sceneNumber` 在 Settings 中仅供查询，实际由 `DphPublisher` 自增维护
- 后续可通过命令方式提供"重置景幅号"功能，但第一阶段暂不开放
- `DphStatus` 通过 `GET /api/runtime-settings` 的只读字段返回

## DphParamsChanged 事件定义

```cpp
// GenericPackets.h 新增
const uint32_t PAYLOAD_TYPE_DPH_PARAMS_CHANGED = 103;
const uint16_t SOURCE_RUNTIME_SETTINGS = 205;

// RadarRuntimeSettings 为 trivially copyable struct，可直接使用 packDataToPayload
template<>
inline uint32_t getPayloadTypeConstant<RadarRuntimeSettings>() {
    return PAYLOAD_TYPE_DPH_PARAMS_CHANGED;
}
```

- `sourceType = SOURCE_RUNTIME_SETTINGS`
- `dispatchTarget = UI_RADARWIDGET`（指向 DPH 相关组件）
- payload 为 trivially copyable `RadarRuntimeSettings`，通过 `packDataToPayload<>` 打包
- 第一阶段不使用 JSON payload 或 typed event

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/runtime-settings` | 读取当前运行时参数 + 只读状态 |
| `PUT` | `/api/runtime-settings` | 全量替换运行时参数（触发 `DphParamsChanged` 事件） |

**PUT 语义**：
- 全量替换，不允许局部字段更新
- 后端校验完整 DTO，非法字段/越界值返回 400
- 成功时返回后端确认后的完整 DTO（与设备台账原则一致）
- 前端以后端返回值更新本地显示

## 与现有模块的关系

- `DphPublisher` 不再从固定默认值构造 `DataPackageHeader`，改为从缓存读取
- `DphPublisher` 新增 `applyRuntimeSettings(const RadarRuntimeSettings&)` 方法
- `DphPublisher` 不直接访问 SystemBus
- `DphParamsChanged` 事件通过 SystemBus 的 `DataPacket` 机制发布
- 不影响 `RadarWorkModeController`（工作模式状态机仍独立运行）
- 不影响 `RadarDataProcessor`（航迹处理不依赖运行时参数）
