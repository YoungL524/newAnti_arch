业务名称：雷达工作状态控制

触发源：
- UI 点击开始/待机
- 命令行输入 work/standby （仅用作当前无UI测试，后续会通过UI触发）

输入数据：
- 用户请求的目标状态：Working 或 Standby

内部状态：
- Standby
- Starting
- Working
- Stopping
- Fault

处理规则：
- Standby 收到开始请求：进入 Starting，发送 workStandby=1
- Starting 超过 300ms 后无错误：进入 Working
- Working 收到待机请求：进入 Stopping，发送 workStandby=0
- Stopping 超过 300ms 后无错误：进入 Standby
- 任意发送失败：进入 Fault

输出事件：
- RadarStateChanged
- WorkModeCommand

是否需要落库：
- 是，记录操作时间、目标状态、结果

是否影响 UI：
- 是，影响按钮文案、航迹显示是否活跃、状态栏

异常/超时规则：
- 发包失败进入 Fault
- 后续如果有 ACK，则 ACK 超时进入 Fault
