# 05 - 核心流程

> 核心流程描述系统最重要的数据和控制路径。  
> 这些流程应长期稳定，局部模块可以替换，但主路径不应随意改变。

## 1. 上行航迹显示流程

```mermaid
sequenceDiagram
    participant Radar as 雷达 / test_comm
    participant Comm as 通信接入
    participant Adapter as 协议适配
    participant Bus as SystemBus
    participant Track as TrackDisplayManager
    participant API as WebApiController
    participant UI as React Web

    Radar->>Comm: UDP 厂家协议数据
    Comm->>Adapter: raw bytes
    Adapter->>Adapter: parse GeneralPackage
    Adapter->>Bus: publish TrackPoint event
    Bus->>Track: dispatch TrackPoint
    Track->>Track: apply display rules
    Track->>API: TrackDisplaySnapshot
    API->>UI: WebSocket tracks
```

关键原则：

- Web 不接收厂家协议；
- 上位机不做航迹起批/消失算法；
- UI 接收的是显示快照。

## 2. 下行工作状态控制流程

```mermaid
sequenceDiagram
    participant UI as React Web
    participant API as WebApiController
    participant Work as RadarWorkModeController
    participant Bus as SystemBus
    participant Router as BusToCommRouter
    participant Comm as 通信接入
    participant Radar as 雷达 / test_comm

    UI->>API: POST /api/start or /api/stop
    API->>Work: requestWork/requestStandby
    Work->>Bus: publish workStandby command
    Bus->>Router: dispatch command
    Router->>Comm: sendTo(endpoint, target)
    Comm->>Radar: UDP workStandby
    Radar-->>Comm: workStandby echo
    Comm-->>Work: state echo through processor/bus
```

关键原则：

- 工作状态由后端状态机管理；
- UI 不直接拼 workStandby 协议包；
- 状态反馈最终同步给 Web。

## 3. DPH 参数更新与周期发送流程

```mermaid
sequenceDiagram
    participant UI as React Web
    participant API as WebApiController
    participant Runtime as RuntimeSettingsService
    participant Bus as SystemBus
    participant DPH as DphPublisher
    participant Comm as 通信接入
    participant Radar as 雷达 / test_comm

    UI->>API: PUT /api/runtime partial params
    API->>Runtime: apply partial update
    Runtime->>Runtime: merge full snapshot
    Runtime->>Bus: publish DphParamsChanged
    Bus->>DPH: dispatch event
    DPH->>DPH: update cached params

    loop every 50ms
        DPH->>DPH: build DPH from cached params
        DPH->>Comm: sendTo dph target
        Comm->>Radar: UDP DPH
    end
```

关键原则：

- UI 只在参数变化时提交；
- 后端持有完整有效快照；
- DPH publisher 不轮询总线；
- 50ms 周期只负责按最近参数发送。

## 4. 任务切换流程

```mermaid
sequenceDiagram
    participant UI as React Web
    participant API as WebApiController
    participant Task as TaskService
    participant Device as DeviceRegistry
    participant Store as DataStore
    participant Track as TrackDisplayManager

    UI->>API: activate task
    API->>Task: activate(taskId)
    Task->>Device: load task devices
    Task->>Store: load task logs/history
    Task->>Track: set task context/filter
    API-->>UI: task context snapshot
```

固定行为：

- 切换任务时加载关联设备；
- 切换任务时加载历史航迹；
- 切换任务时加载日志/操作记录；
- UI 地图、PPI、表格跟随任务上下文过滤。

## 5. 设备台账加载流程

```mermaid
sequenceDiagram
    participant UI as React Web
    participant API as WebApiController
    participant Device as DeviceRegistry
    participant Store as DataStore
    participant Config as endpoints.json

    UI->>API: GET /api/devices
    API->>Device: list devices
    Device->>Store: load DeviceInfo
    Device->>Config: resolve endpoint binding
    Device-->>API: DeviceInfo + runtime state
    API-->>UI: fixed Device DTO
```

关键原则：

- 前端加载后端设备台账；
- 通信端点仍由配置驱动；
- 设备和端点通过 binding 关联。
