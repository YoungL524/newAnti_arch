# 控制链路 GUI 联试

运行 `python tools/control_link_gui.py`，仅依赖 Python 标准库的 Tkinter。

1. 工具固定监听 `127.0.0.1:2345` 的周期 `0x0001` 和 `127.0.0.1:1234` 的一次性 `0xFFFF`；两种报文无需修改设备台账目标。
2. 在窗口填写 DCMP 内部 UDP 入口，默认 `127.0.0.1:7788`，点击“开始监听”。工具每秒发送 DP/SP 在线心跳，阵面位图固定 `0x01`（只声明 1 号阵面），并显示已提交次数；可取消勾选其中一路观察周期发送暂停。
3. 在 DCMP 激活新建或沿用的任务：双心跳在线后应连续收到 `0x0001`；开始采集后另收到一次 `0xFFFF 开始工作 workStandbyMode=1`，停止采集后另收到一次 `0xFFFF 待机 workStandbyMode=0`，而 `0x0001` 仍继续。完成任务后 `0x0001` 停止。
4. 在 DCMP **开始采集**后点击窗口的“开始模拟航迹”：工具每 200 ms 向 `127.0.0.1:7788` 发送一包 656 字节 `0x0100`，固定为 1 号阵面、目标 ID 1，距离和方位平滑变化。停止模拟时发送一次 `packFlag=0` 消亡包。任务必须绑定 1 号阵面；未开始采集时 Core 的航迹入口会按合同拒收。

窗口验证 944 字节 `0x0001` 和 68 字节 `0xFFFF` 报文的封装、协议版本及控制字；接收成功不代表设备执行成功。无效报文会显示原因，不改变最近有效控制状态。端口被占用时先关闭占用它的程序。
