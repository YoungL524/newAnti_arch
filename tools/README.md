# 控制链路 GUI 联试

运行 `python tools/control_link_gui.py`，仅依赖 Python 标准库的 Tkinter。

1. 在 DCMP 设备台账中，将 **DPH 目标**配置为本机 `127.0.0.1:7790`；若跨机器联试，改为本机可达的网卡 IP，并在窗口填写相同的监听 IP 和端口。
2. 在窗口填写 DCMP 内部 UDP 入口，默认 `127.0.0.1:7788`，点击“开始监听”。工具每秒发送 DP/SP 在线心跳；可取消勾选其中一路观察发送暂停。
3. 在 DCMP 创建或选择任务并开始采集：窗口应连续显示 `启动/保持采集`、`F_UI_STBY_Ctrl=1`。停止采集：窗口应收到一次 `待机/停止采集`、`F_UI_STBY_Ctrl=0`，随后不再收到周期控制包。

窗口只验证收到的 944 字节 `0x0001` 报文封装、协议版本和采集控制字；接收成功不代表设备执行成功。无效报文会显示原因，不改变最近有效控制状态。重新配置监听端口前先点击“停止”。
